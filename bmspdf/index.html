Offline PDF Splitter & Merger / 完全オフライン PDF分割・結合ツール

100% client-side processing. No files are ever uploaded to any server.
ブラウザ内完結・外部通信ゼロ。機密書類でも安全に分割・結合できます。

1. Select a PDF File / PDFファイルを選択

No file selected. / ファイルが選択されていません。

2. Choose Split / Extract Pattern / 分割・抽出パターンを指定

Outputs two PDFs: Odd pages (1, 3, 5...) and Even pages (2, 4, 6...).
奇数ページまとめ（1,3,5...）と 偶数ページまとめ（2,4,6...）の2ファイルを出力します。
Extract pages matching: n + (n = 0, 1, 2...)
Example: 3n + 2 extracts pages 2, 5, 8, 11... into a single PDF.
例：「3n + 2」→ 2, 5, 8, 11... ページ目を1つのPDFに抽出します。
Split every page(s) / ページごとに別々のPDFへ分割
Example: 1 splits every page individually; 2 splits into 2-page chunks.
例：「1」なら全ページバラバラに保存。「2」なら2ページずつ分割保存。
• Use comma (,) to combine pages into one PDF (e.g. 1-3, 5).
• Use slash (/) to split into separate PDFs (e.g. 1-2 / 3-5).
• カンマ（,）で1つのPDFに結合、スラッシュ（/）で別ファイルに分割出力します。

1. Add PDF Files / 結合するPDFを追加（複数選択可）

You can select multiple files at once or add more files later.
複数ファイルをまとめて選択するか、後から追加して順番を並べ替えられます。
